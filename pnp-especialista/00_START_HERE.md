# START HERE — PNP ESPECIALISTA

## Missão
Transformar a landing page existente do **Personal na Prática / Pensando como Empresário** na nova página **PNP ESPECIALISTA — Aprenda a Aplicar**, cuja formação central é **Especialista em Emagrecimento e Definição Muscular**.

Referência visual/estrutural: `https://personalnapratica.com.br/`

## Regra mais importante
Esta tarefa **não é um redesign completo**. A página atual é referência de estrutura, componentes, grid, tipografia, cores, fundos, cards, botões, animações, espaçamentos, responsividade, prova social, quiz, FAQ e ritmo visual.

A página antiga **não é fonte de posicionamento**. O antigo eixo `marketing → vendas → agenda → faturamento → negócio` deve dar lugar a `ciência → prescrição → periodização → aplicação → resultados`.

## Fluxo de execução
1. Inspecione o projeto atual e identifique stack, rota, componentes, assets e integrações.
2. Faça inventário antes de editar.
3. Reaproveite componentes estáveis.
4. Adapte cada seção conforme o mapeamento.
5. Centralize oferta/checkout/configurações fáceis de editar.
6. Rode build e página.
7. Valide desktop, tablet e mobile.
8. Corrija console, overflow, CTAs, FAQ, quiz e layout.
9. Execute o checklist final.
